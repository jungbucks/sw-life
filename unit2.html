2-1 피지컬 컴퓨팅 — 소프트웨어에 몸을 달다 🤖

1단원의 렌즈가 그대로 온다 — 다만 이번엔 입력과 출력이 진짜 세상이다.

📡 센서 (입력)→ 🧠 마이크로컨트롤러 (처리)→ ⚙️ 액추에이터 (출력)

센서는 세상을 숫자로 읽어 들이고(빛·소리·거리·온도…), 마이크로컨트롤러(아두이노, 마이크로비트 같은 작은 컴퓨터)가 우리가 짠 소프트웨어로 판단하고, 액추에이터가 세상에 행동한다(불 켜기·움직이기·소리 내기). 이 조합이 피지컬 컴퓨팅이다.

역할부품읽거나 하는 것
센서 📡
(세상 → 숫자)		빛 센서 / 소리 센서밝기, 소리 크기
초음파(거리) 센서 / 온도 센서물체까지 거리, 온도
버튼·터치 / 가속도 센서눌림, 기울기·움직임
액추에이터 ⚙️
(숫자 → 세상)		LED / 디스플레이빛과 정보 표시
서보 모터 / 스피커·부저 / 펌프움직임, 소리, 물 주기

작품 해부 실습 — 스마트 화분은 어떻게 일할까

피지컬 컴퓨팅 작품을 만나면 먼저 세 조각으로 해부하라. "흙이 마르면 스스로 물을 주는 화분"을 분해해 보자.

각 부품을 클릭해 역할을 밝혀 보자 — 어떤 부품이 입력·처리·출력일까?
💡 분석의 순서 어떤 작품이든 ① 무엇을 감지하나(센서) → ② 어떤 규칙으로 판단하나(소프트웨어) → ③ 무엇을 움직이나(액추에이터) 순서로 물으면 구성과 작동 원리 분석이 끝난다.

같은 부품, 다른 쓰임 — 부품의 용도는 정해져 있지 않다

부품쓰임새 1쓰임새 2쓰임새 3
거리 센서자동문 (사람 감지)자동 손소독기 (손 감지)미아 방지 가방 (멀어짐 감지)
소리 센서박수 스위치교실 소음 경보리듬 게임 입력
LED조명브레이크 경고등로봇의 감정 표현

같은 거리 센서가 문을 열기도, 소독약을 뿌리기도, 부모님께 알림을 보내기도 한다 — 부품의 용도를 정하는 것은 부품이 아니라 소프트웨어(판단 규칙)다. 이 유연함 덕분에 몇 가지 부품만으로도 무한한 작품이 가능하다.

2-2 부품 골라 조립하기 — 아이디어 → 시스템 🧩

아이디어를 시스템으로 바꾸는 열쇠는 "무엇을 감지하고, 무엇을 움직일까"의 선택이다.

🎮 피지컬 컴퓨팅 조립 시뮬레이터 LIVE
① 미션 선택
② 센서 선택 (입력)
③ 액추에이터 선택 (출력)
미션을 고르고, 알맞은 센서와 액추에이터를 골라 조립해 보자!
🚨 오개념 주의보 — 부품보다 판단 규칙이 소프트웨어다 같은 소리 센서+LED라도 "박수 2번에 켜기"와 "시끄러우면 경고등"은 완전히 다른 작품이다. 부품은 몸이고, 판단 규칙(소프트웨어)이 작품의 영혼이다 — 그래서 부품 선택 다음엔 반드시 "어떤 규칙으로?"를 설계한다.

2-3 미디어 아트 — 관객이 작품을 완성한다 🎨

피지컬 컴퓨팅이 예술을 만나면 — 작품이 관객을 감지하고 반응하기 시작한다.

거대한 전시장 벽에 꽃이 피어나고, 관객이 다가가면 꽃잎이 흩어진다. 관객의 위치(센서 입력)를 소프트웨어가 읽고, 영상과 소리(출력)를 실시간으로 그려 내는 것 — 관객의 참여가 없으면 미완성인 예술, 이것이 미디어 아트다.

🎮 1평짜리 미디어 아트 체험 LIVE

아래 무대 위에서 마우스(또는 손가락)를 움직여 보자 — 너의 움직임이 입력이고, 빛의 궤적이 출력이다.

🖱️ 여기에서 움직여 보세요
방금 체험한 구조: 포인터 위치(센서 입력) → 색·크기 계산(소프트웨어 처리) → 빛 파티클(출력). 실제 전시장은 카메라·거리 센서가 관객 전체를 읽는다는 점만 다르다!

여기서 소프트웨어의 "가치"가 드러난다

  • 상호작용 — 그림은 걸려 있지만, 미디어 아트는 관객마다 다르게 반응한다. 같은 작품이 매번 새 작품이 된다.
  • 무한 변신 — 하드웨어는 그대로 두고 코드만 바꾸면 완전히 다른 작품. 물감은 다시 살 수 없지만 소프트웨어는 무한히 고쳐 그릴 수 있다.
  • 표현의 확장 — 소리를 색으로, 심장 박동을 파도로 — 사람 손으로 불가능한 번역을 소프트웨어가 해 낸다.

2-4 웨어러블 — 입는 소프트웨어, 퍼지는 가치 🧥

피지컬 컴퓨팅을 몸에 입히면 웨어러블이 된다. 그리고 작품은 공유될 때 가치가 커진다.

스마트워치(심박 센서 → 건강 알림)만 웨어러블이 아니다. 전도성 실과 LED, 작은 컨트롤러만 있으면 교실에서도 만들 수 있다:

작품 아이디어센서 (입력)액추에이터 (출력)
🚴 야간 자전거 안전 재킷가속도 센서 (감속 감지)등판의 LED 브레이크 등
🎒 미아 방지 가방거리 센서 (보호자와 멀어짐)부저 알림
🧢 자외선 경보 모자빛(UV) 센서챙의 LED 색 변화

만들었다면 — 공유가 가치를 확산시킨다

  • 발표·전시: 작동 영상과 함께 "왜 만들었는지(문제)"를 보여 주면 다음 제작자에게 영감이 된다
  • 제작 과정 공개: 부품 목록·회로 연결·코드를 공개하면 누구든 따라 만들고 개선할 수 있다 — 오픈 소스 정신
  • 피드백 받기: "장갑을 끼면 버튼을 못 눌러요" 같은 사용 후기가 다음 버전을 만든다
💡 소프트웨어 가치의 마지막 조각 물건은 나누면 반이 되지만, 소프트웨어와 지식은 나눠도 줄지 않고 오히려 자란다. 전 세계 아두이노 작품 대부분이 누군가 공개한 회로와 코드에서 출발했다 — 너의 작품도 누군가의 출발점이 될 수 있다.
